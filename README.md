# InvestiMate

A stock prediction app, rebuilt from scratch.

## Origins

InvestiMate started in spring 2025 as a CS 407 team project at the University of Oregon, built by Anthony (David) Cano-Luna with Jack Lund and Dom Ellis as original contributors. That project lives at [AnthonyCano/InvestiMate](https://github.com/AnthonyCano/InvestiMate).

This repository is a from-scratch rewrite by Anthony (David) Cano-Luna. No code from the original project was carried over.
